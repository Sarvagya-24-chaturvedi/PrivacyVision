How to Run Demos for Judging

  1. Click any demo above to open the test scenario.
  2. Open the PrivacyVision extension popup from the Chrome toolbar.
  3. Click [Capture Context] — observe the Before / After tab showing original local vs sanitized visual.
  4. Click [Toggle Overlay] to see real-time bounding box annotations on the webpage.
  5. Click [Run Agent] — observe the remote VLM reason over sanitized context and execute the local browser action.
