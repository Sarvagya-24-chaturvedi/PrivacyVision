## 🛡️ Privacy & Security Commitments

PrivacyVision is built from the ground up with local-first privacy safeguards:
- **Client-Side Redaction**: Sensitive personal identifiable information (PII) like passwords, emails, phone numbers, and credentials are obfuscated client-side inside the browser *before* any visual or DOM state is processed.
- **Action Confirmation**: Dangerous system actions (form submits, deletions, purchases) require explicit user confirmation.
- **Zero Ingestion of Private Data**: We do not store, log, or track user interaction sessions.

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability or privacy leak within PrivacyVision:

1. **Please do NOT open a public GitHub issue.**
2. Instead, report it privately by opening a [GitHub Security Advisory](https://github.com/Sarvagya-24-chaturvedi/PrivacyVision/security/advisories/new) or contacting the maintainers directly.
3. Include:
   - Detailed description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

We will respond promptly, acknowledge receipt, and coordinate a patch release. Thank you for helping keep PrivacyVision safe!
